# JIM Fitness – Front Door
Branded launcher that shows a JIM splash screen and loads the Apps Script dashboard full-screen.
Requires the Apps Script deployment's **Who has access** set to **Anyone** (Safari blocks Google sign-in inside an embedded page).
Publish: Settings → Pages → Deploy from a branch → main / (root). Then open https://jaylennunnally.github.io/jim-fitness/ on iPhone Safari → Share → Add to Home Screen.
